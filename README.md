# ACME Consumers Food Products — Cash Memo

Mobile-friendly cash memo generator (Bangladesh-style shop memo).

## Features

- Fixed shop title, memo number, date
- Client name, address, remarks
- Product table: SL, name, qty, unit, rate, amount
- Auto total + amount in words
- Payment status (Fully Paid / Due / Partially Paid)
- Authorized / Receiver signatures
- Add / edit / delete product rows
- Reset & PDF download

## Run locally

Open `index.html` in a browser, or use any static server:

```bash
npx serve .
```

## GitHub Pages

1. Push this repo to GitHub
2. **Settings → Pages → Source**: Deploy from branch `main` / folder `/ (root)`
